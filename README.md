# Локальный запуск приложения

Используйте ветку `local-develop` и запускайте команды из корня проекта.
Требуются запущенный Docker Desktop с Linux-контейнерами и свободные порты
443, 5000 и 8001. Настройки БД уже заполнены; сертификат и ключ должны
находиться в `ssl/nginx.crt` и `ssl/nginx.key`.

## 1. Открыть SSH-туннель

В отдельном терминале выполните команду и оставьте терминал открытым:

```powershell
ssh -N -L 127.0.0.1:15432:localhost:5432 restricted_user@193.232.208.50
```

## 2. Запустить контейнеры

В другом терминале, из корня проекта:

```powershell
docker-compose up -d --build
docker-compose ps
```

Откройте **https://localhost**. Для самоподписанного сертификата разрешите
переход в браузере. Без действующей сессии откроется страница входа,
с действующей сессией — дашборд. Frontend уже собран, архив распаковывается
автоматически при сборке контейнера.

## Логи и остановка

```powershell
docker-compose logs --tail=100
docker-compose down
```

Для повторного запуска используйте `docker-compose up -d --build`.
При обычной остановке не добавляйте `-v`: том хранит ключ сессий.
Команды также работают с `docker compose` вместо `docker-compose`.

Подробнее: [настройки, сертификат и обновление frontend](deploy/LOCAL_DEPLOYMENT.md).
