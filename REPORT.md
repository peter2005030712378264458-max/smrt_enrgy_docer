## Основные изменения

### Адаптер и работа с источником

- Имена, типы, комментарии столбцов и права SELECT берутся из каталога PostgreSQL.
  Синонимы помогают предложить сопоставление; оператор подтверждает его смысл,
  единицы и интервал измерений.
- Структура источника возвращается даже при тайм-ауте примеров строк;
  в таком случае выводится предупреждение.
- Отсутствующие или недоступные необязательные столбцы дают NULL и предупреждение.
  Остальные доступные измерения продолжают агрегироваться.
- Время и идентификатор счётчика обязательны. Отсутствие этих столбцов,
  NULL времени, пустой/NULL ID в выбранном периоде или неверный тип
  останавливают расчёт до замены старых агрегатов.
- Общая мощность берётся из общего показания или суммы всех трёх корректных фаз.
  Частичные фазы сохраняются отдельно. NaN и Infinity обрабатываются как
  отсутствующие измерения; настоящий ноль сохраняется.
- После изменения структуры требуется новый preview. Сохраняются подтверждение
  профиля, проверка перед записью, контроль дубликатов, покрытия и справочника.

### Агрегаты и расчёты

- В часовые и суточные таблицы добавлены счётчики корректных значений метрик.
  Команда `upgrade-aggregates` добавляет их в существующие таблицы;
  у старых строк счётчики остаются неизвестными до пересчёта.
- Средние взвешиваются по числу корректных значений соответствующей метрики.
  Недельная мощность сначала усредняется по времени для каждого счётчика,
  затем складывается между счётчиками.
- Django и аналитика переведены на сохранённую энергию
  (`ENERGY_USE_STORED_ENERGY=1`) после проверки истории.
  Неизвестная энергия не подменяется нулём или неполным общим итогом.
- Часовые и суточные агрегаты заменяются одной транзакцией на сутки.
  Сохранены блокировки, откат, идемпотентность и исключение незавершённых суток.
- Нормализация вычисляется один раз на строку; JIT выключен только
  в читающей сессии адаптера. Глобальные настройки источника не менялись.

### Дашборд и неполные данные

Исправлена ошибка, из-за которой NULL мощности одного счётчика скрывал общий
график, хотя у остальных счётчиков значения были. Первоначальная проверка
HTTP 200 и числа временных точек не выявила отсутствия значений линии;
добавлены проверки реальной мощности и её обработки фронтендом.

API сохраняет строгий полный итог и отдельно возвращает доступную мощность
с числом учтённых счётчиков. График и карточки показывают доступные значения
с отметкой полноты, например **«47 из 49»**. В подсказке графика видно число
участников каждой точки. Полностью пустая точка остаётся пропуском.

Полная энергия остаётся «—», если исходных измерений для неё недостаточно.
Интерфейс объясняет причину; непроверенная старая история отмечается отдельно.

### Развёртывание

Подготовлены отдельные Compose-файлы для приложения на ВМ и туннеля на ПК.
`start.sh` запускает БД, соединение с источником и сервисы, поддерживает
Compose 1.29.2 и современный Compose. Исправлена ошибка `ContainerConfig`
старого Compose при обновлении образов.

Три работающих контейнера прежнего дашборда остановлены. Существующий
PostgreSQL CMDBuild, том новой БД и постоянный ключ Django сохранены.
Перед обновлениями сделаны резервные копии БД/настроек/кода и сохранены
прежние образы для отката. Дополнительная правка графика обновила только
backend и frontend.

## Ограничения и оставшаяся работа

- 17 апреля и 2 октября остались непроверенными из-за тайм-аутов;
  нужна отдельная проверка производительности чтения этих дней.
- Для остальных не прошедших проверку дней нужны полные/исправленные
  исходные показания, затем новый preview и пересчёт.
- Полностью отсутствующий за выбранный период счётчик нельзя обнаружить
  без ожидаемого перечня. Полнота графика считается относительно счётчиков,
  представленных в агрегатах этого периода.
- Внутренний доступ разрешён для обнаруженных сетей `193.232.208.32/27`
  и `192.168.1.0/24`. Подсети всех рабочих ПК не подтверждены;
  дополнительные сети добавляет администратор. Сертификат самоподписанный.
- Браузерный рендеринг и перетаскивание вручную не проверены: средства
  Computer Use / Browser Use были недоступны. Проверены SQL, HTTP,
  реальные значения и функции фронтенда.
