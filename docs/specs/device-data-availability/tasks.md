523227 пригодных временных меток, 49 наблюдаемых устройств в обоих вариантах.
Это одиночный последовательный замер с разным состоянием кеша; значительное
ускорение от отключения JIT не заявляется. Основное сокращение повторной
работы обеспечивается общим кешем дневных статистик, проверенным тестом.

Первоначальные данные о показаниях (каталог, индексы, границы истории) читались
без изменения. С сентября есть электрическая история; климат и meteo — с октября.
Для месячного периода климатическим устройствам может не хватать 21 дня
предшествующей стабильной истории; unknown является ожидаемым исходом.

Ограничения: сравнение количества, не временное покрытие; исторический эталон
не доказывает физическую исправность. Стабильная системная деградация может
занизить эмпирический эталон. Событийные устройства без стабильного эталона
не объявляются нормальными. NULL/0 исключаются только в этом отчёте.
