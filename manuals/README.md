# Руководства Smart Energy

Комплект документации для текущей версии проекта. Подготовлен 12 ноября 2026 года
по исходному коду, Compose-файлам и отчёту об обновлении ВМ42 от 6 ноября.
Дата подготовки документации не означает повторную проверку работающей ВМ.

| Документ | Для кого | Что внутри |
| --- | --- | --- |
| [Инструкция по установке](INSTALLATION.md) | Специалист, который готовит запуск | Доступ к существующему сайту, локальная установка, установка на ВМ, проверка запуска |
| [Руководство пользователя](USER_GUIDE.md) | Пользователь приложения | Вход, дашборд, фильтры, состояние датчиков, аналитика, уведомления |
| [Руководство администратора](ADMIN_GUIDE.md) | Администратор приложения и сервера | Права, источники, пересчёт, расписание, диагностика, резервные копии и обновление |

Если сайт уже работает на ВМ и нужно только открыть его, начните с
[выбора способа доступа](INSTALLATION.md#2-доступ-к-уже-установленному-приложению).
Устанавливать локальную копию приложения для этого не требуется.

Адреса в примерах относятся к существующей инфраструктуре:

- **ВМ42 — `193.232.208.42`**: приложение и его отдельная база PostgreSQL 17.
- **ВМ50 — `193.232.208.50`**: исходные показания и справочники.
- **`https://localhost:8443/`**: локальное приложение при штатной workstation-установке.
- **`https://localhost:8444/`**: выбранный на данном ПК порт SSH-доступа к приложению ВМ42.

`localhost` всегда обозначает компьютер, на котором открыт браузер. Номер порта
сам по себе не определяет версию приложения: это зависит от запущенного туннеля
или локального контейнера.

Технические подробности и исторические результаты: [отчёт ВМ42](../deploy/vm42/RELEASE_20261106.md),
[контракты БД](../DATABASE.md), [документация адаптера](../adapter/README.md).
